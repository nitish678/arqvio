# Security disclosure

ARQVIO research can affect trading only through explicit user activation. This repository does not grant trading access.

## Do not send

- Licence keys, account logins/ passwords, HWID-bound material or broker tokens.
- Credentials stored in OS secret stores or environment files.
- Screenshots/logs containing account numbers or MT5 server identity linked to an identity.

## Reporting concerns

Report privately to the repository maintainer's GitHub account profile or profile-designated contact. Do not post exploit details, live terminal exploits or trading-credential bypasses in public issues. State environment and exact reproduction steps without credentials.

## Engine safety context

Deployment/execution APIs are explicit owner actions. Automated trading requires terminal configuration and user action; no component defaults to live trading. Backtest results are not market predictions.
